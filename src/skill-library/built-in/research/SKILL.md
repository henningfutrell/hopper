# Research

Use this skill when the job is asked to research, not to do the work.

## Method

1. Write the question again in one sentence. If the question is not clear, say what you take it to mean.
2. Find the sources that can answer it: the code, its history, the issues and pull requests, the design documents, and
   documents outside the repository when the question needs them.
3. Read before you conclude. Note each fact with the place it comes from: a file and line, a commit, a link.
4. Separate what you found from what you think. Give each conclusion a confidence, and say what would change it.
5. Stop when more reading would not change the answer. Name what is still open as open threads.

## The report

Write the report as the job rules say, with its labels in order. Keep the findings short: lists, code spans and links,
with the summary first. Do not change code while you research.
