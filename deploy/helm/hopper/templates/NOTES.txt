{{- if .Values.ingress.enabled }}
Open {{ .Values.ingress.publicUrl | default (printf "https://%s" .Values.ingress.host) }}
{{- else }}
Reach it from this computer:
  kubectl --namespace {{ .Release.Namespace }} port-forward svc/{{ include "hopper.fullname" . }} {{ .Values.port }}
then open http://localhost:{{ .Values.port }}/
{{- end }}
Sign in with GitHub: the first person to do so is the admin.

The first start makes the master key and shows it once, in the UI. Keep it in a password manager, then:
  kubectl --namespace {{ .Release.Namespace }} create secret generic {{ .Values.masterKey.existingSecret | default (printf "%s-master-key" (include "hopper.fullname" .)) }} --from-literal=master-key=<the key>
  kubectl --namespace {{ .Release.Namespace }} rollout restart deployment/{{ include "hopper.fullname" . }}
