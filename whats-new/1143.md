- A pull request left on an old base branch now moves to the branch where changes land, a pull request with nothing left to land is closed, and each pull request now says in a comment what the hopper does with it.
- A pull request that waits for a rebase behind other work now gets one within an hour, and a pull request left on the old base branch now moves to the branch where changes land even when no job watches it.
