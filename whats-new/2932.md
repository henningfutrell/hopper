- A machine signed in to a Claude account with no usage limits, such as an Enterprise plan, now runs jobs on all its lanes, not on one.
- A machine is no longer kept from removal by jobs that wait there but can go on from another machine.
- You can now see and change the usage limits and soft lanes from the command line, for all machines or for one.
- A machine's card now lists the jobs that keep it from removal, each with a link. A job that waits there can be released, so it goes on from another machine.
