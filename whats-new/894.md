- Updating a container install no longer takes the whole hopper down when a new version adds a service, and when the new version does not start, the update puts the old one back by itself.
- A container install keeps no settings file with secrets in it any more: the first update moves your settings into the compose file and asks for the master key at start only.
- New help pages explain remote access and how to give an agent long-lived access with grants, linked from their Settings pages.
