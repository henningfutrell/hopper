- When a program in a job runs out of memory for its JavaScript heap, such as a type check, the job now shows which program it was, its memory limit and how much memory it used.
- When the same program runs out of memory in many jobs, the hopper now stops running those jobs again and shows the program on Failures, so a person can fix it.
- When a program in a job stops with a core dump, or the system stops it because memory ran out, the job now shows which program it was.
- When a program in a job runs out of memory for its JavaScript heap, the hopper now runs the job again once with more memory, when the machine has room, before it asks a person.
